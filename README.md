# DataForge

DataForge is a production-style, beginner-friendly data engineering portfolio project.

The goal is to build an intelligent data quality and pipeline reliability platform step by step. When complete, DataForge will ingest data from multiple sources, store raw data in a Bronze layer, transform it with PySpark, validate data quality, quarantine invalid records, produce Silver and Gold datasets, run SQL analytics, track pipeline health, detect anomalies and probable root causes, and present insights through a Streamlit dashboard.

This repository currently contains only the initial project structure and configuration files. Future milestones will add implementation incrementally.

## Planned Capabilities

- Multi-source data ingestion
- Bronze, Silver, Gold, and quarantine data layers
- PySpark transformations
- Data quality validation
- SQL analytics with DuckDB
- Pipeline monitoring and health tracking
- Anomaly and root cause analysis
- Streamlit dashboard
- Automated tests with pytest
- GitHub Actions CI

## Project Status

Initial scaffold only. No pipeline logic has been implemented yet.
